# 1. MUAMMO — bitta ziddiyat

> ### Qonun **INN** talab qiladi. Javon esa **savdo nomi** bilan to'la.

Vrach retseptga **xalqaro nom** yozadi (masalan `Amoxicillin 500 mg`).
Dorixonada esa bu nom ostida **hech narsa yo'q** — javonda **12 ta boshqa nom** turadi:
`Amoxil` · `Ospamox` · `Flemoxin` · `Hiconcil` · `Amoksiklav` · ...

**Farmatsevt ularning orasidan bittasini tanlashi kerak. 3 daqiqada. Xotiradan. Bemor oldida turib.**

Bu **bitta** muammo. Qolgan hammasi — uning oqibati.

# 6. HOW — qanday ishlaydi

**5 qadam. 4 soniya mashina + 35 soniya inson = 40 soniya.**

```
Retsept (skan yoki INN)
        │
   [1] O'QISH ───────────── 0.8 s
       kirill → lotin · imlo xatosi · doza/shakl ajratish
       → INN + ATC kodi
       ├── ishonch past → ⛔ ODDIY SO'ROV: "qaysi dori?"  ← xavfsizlik
       └── ishonchli → davom
        │
   [2] QOIDALAR ─────────── 0.1 s
       allergiya · yosh · homiladorlik · retseptli/retseptsiz
       → mos kelmaydiganlar CHIQARILADI (modeldan ustun)
        │
   [3] TANLASH ──────────── 1.2 s
       doza mosligi + shakl + bioekvivalentlik + narx + qoldiq
       → BITTA eng yaxshi variant + "nega"
        │
   [4] QOLDIQ ───────────── 0.9 s
       qaysi dorixonada bor (48 soat ehtimoli)
       → yo'q bo'lsa: eng yaqin mavjud nuqta
        │
   [5] TASDIQ ───────────── 35 s
       farmatsevt ko'radi → bosadi → yozuv saqlanadi
```
